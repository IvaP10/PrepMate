# Support

PrepMate is a local-first macOS application distributed from the official
website. It has no hosted application support queue, account recovery, paid
support plan, automatic analytics, or support account.

Use the public support route listed on the official website for setup and
reproducible product issues. Do not send API keys, resumes, transcripts,
provider responses, database files, or unredacted local paths.

Before contacting support:

1. Record the PrepMate version and whether the Mac is Apple Silicon or Intel.
2. Note whether the issue occurs in the packaged app or an authorized source
   development checkout.
3. Reproduce the issue with synthetic resume and interview data where possible.
4. Include only redacted diagnostics and the exact visible error.

Provider outages, provider retention, provider billing, and provider account
issues must be reported to the selected AI provider. PrepMate does not receive
or manage those provider accounts.
