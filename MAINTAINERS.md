# Maintainers

PrepMate is maintained privately by the project owner through the private
source repository and its protected review process. Customer builds are native
desktop artifacts; the source repository is not a browser deployment.

Changes that affect the local-data boundary, provider requests, encryption,
code execution, licensing, or release artifacts require maintainer review.

The maintainer owns final product-name clearance, copyright approval, Apple
signing and notarization credentials, release storage, public support, and
security-report routing.

Never include private resumes, transcripts, databases, API keys, provider
responses, signing material, or customer data in source changes, build logs,
release assets, or support reports.
